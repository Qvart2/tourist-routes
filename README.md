# Каталог туристических маршрутов

Учебный React-проект по теме №24. Каталог туристических маршрутов.

## Первый этап

- создана компонентная структура;
- подключён React Router;
- добавлена навигация;
- созданы страницы «Главная», «Маршруты», «Маршрут» и «Добавить маршрут»;
- добавлен динамический адрес `/routes/:routeId`;
- сделаны начальные адаптивные стили.

## Запуск

```bash
npm install
npm run dev
```

Следующий этап: массив тестовых маршрутов, карточки, поиск и фильтрация.
